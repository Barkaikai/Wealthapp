WHY THIS HAPPENS

On Replit, your server must:

Run continuously on port 8000 or 3000

Respond within 60 seconds

Use host="0.0.0.0" so Replit can access it
If not, Replit disconnects → "Connection terminated due to connection timeout".

⚙️ FIX CODE (for Python / FastAPI backend)

Replace your main.py (backend entry) with this exact code 👇

import os
import uvicorn
from fastapi import FastAPI, UploadFile, HTTPException
from fastapi.middleware.cors import CORSMiddleware
import pandas as pd
import io

app = FastAPI()

# ✅ Allow frontend to connect
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # you can replace "*" with your frontend URL for more security
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/")
def home():
    return {"message": "✅ Backend is running smoothly!"}

@app.get("/api/health")
def health_check():
    return {"status": "ok"}

# ✅ Example portfolio endpoint (replace with your real data)
@app.get("/api/portfolio")
def get_portfolio():
    try:
        df = pd.read_csv("portfolio_export_2025-10-24.csv")
        total_value = df["value"].sum()
        return {"total_value": float(total_value), "message": "Portfolio loaded successfully!"}
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@app.post("/api/upload-receipt")
async def upload_receipt(file: UploadFile):
    content = await file.read()
    # Just simulate AI receipt reading
    return {"message": f"Receipt '{file.filename}' uploaded successfully", "summary": "AI found 3 transactions."}

if __name__ == "__main__":
    # ✅ Runs properly inside Replit
    port = int(os.environ.get("PORT", 8000))
    uvicorn.run(app, host="0.0.0.0", port=port)

🧩 FRONTEND FIX (React, Vue, or plain JS)

Make sure all your API calls go to the correct Replit URL:

// example in frontend
const API_URL = window.location.hostname.includes("replit")
  ? "https://" + window.location.hostname.replace("wealthforge.app", "your-backend-name.yourusername.repl.co")
  : "http://localhost:8000";


or simply if backend and frontend are same Repl:

fetch("/api/portfolio")


✅ Important:
If you run frontend and backend in separate Repls, Replit will sleep the backend if inactive.
Use UptimeRobot or Replit’s “Always On” setting to keep it awake.
